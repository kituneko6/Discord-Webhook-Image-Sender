
機能
web（SNS等）やローカルからの画像ファイルを取得しImage padに直接貼り付けられるURLを取得する

動作説明
web、ローカルから画像を取得
画像のサイズをImage padにの最大サイズに縮小（小さい場合はしない）
縮小した画像をDiscord webhookに送信
送信した画像URLをクリップボードにコピー
Image padに張り付け

使用方法
webから任意の画像URLをコピー または 自分のPCから共有したい画像のパスをコピー
張り付けボタンで張り付ける
画像変換＆送信ボタンでDiscordに送信
送信した画像URLがクリップボードにコピーされているので、
VRChatでImage padに直接貼り付けられる
